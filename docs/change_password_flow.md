# Change Password Flow

## Step 1: User Requests Password Change

The user clicks on the "Change Password" button in the settings menu.

## Step 2: Current Password Verification

The app prompts the user to enter their current password for verification.

## Step 3: New Password Entry

If the current password is correct, the app allows the user to enter a new password.

## Step 4: Confirm New Password

The user is prompted to re-enter the new password for confirmation.

## Step 5: Update Password

If the new passwords match, the app updates the user's password.
